# Contributing

Keep changes within the existing TypeScript/npm, Android and Swift package
boundaries. Use strict types and public package APIs. Run checks appropriate to
the changed platform and report exactly which snapshot and scenarios passed.

Use original or synthetic fixtures. Do not add service credentials, account
exports, private URLs, signed media locators, downloaded player scripts, lyrics,
commercial recordings, device identifiers, signing profiles or local build logs.
Do not treat nearby CC0 Studio files as a grant for third-party content.

Retain upstream copyright, license and notice files. A new dependency or native
artifact changes the corresponding-source and notices inventory. Record exact
source pins and build inputs before proposing distribution.

Describe what changed, why, and the tests run. Source review, a successful build,
physical-device validation and permission to publish are distinct outcomes.
