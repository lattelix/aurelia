# Security reports

This source candidate does not yet publish a dedicated private vulnerability
reporting channel or a supported-version policy. Do not publish live secrets,
account data, signed media URLs or a working exploit against someone else's
host in a public issue. A contact channel must be established before a supported
public release is announced.

For local investigation, use a loopback service and synthetic accounts. Describe
the affected source-manifest hash, minimal reproduction and expected boundary.
Redact credentials and personal data. Provider registrations, credentials and
security configuration are the operator's responsibility; none are bundled here.
